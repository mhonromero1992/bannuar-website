# Photo slots

Put Bannuar's own photographs here with these names; each appears in its place on the next build,
converted to AVIF and WebP. Until a file is here, the slot shows its drawing.

| File | Where it shows |
|---|---|
| `office.jpg` | Home and About, beside the office address |
| `hometown.jpg` | About, "From San Juan, La Union" (`npm run fetch:photos` downloads a licensed one) |
| `blood-drive.jpg` | About, beside the blood drive |

Use only photographs Bannuar owns or has written permission to use. No stock photographs of guards:
they would present strangers as Bannuar's people.
